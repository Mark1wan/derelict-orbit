# Loose Props

Set dressing for Kestrel-9: the eleven things that drift loose in the corridors and rooms.
Same pipeline and the same material names as the corridor and room modules in `../` — see
`../KIT_README.md` — so `scripts/palette.gd`'s `KIT_MAP` remaps them with no extra wiring.

## The one rule that differs from the kit

Kit modules sit with their **floor at y = 0** on a 4 m grid. A prop is **centred on its own
origin** instead, because in zero-G the origin is the point it tumbles about. A prop whose
mass is visibly off to one side will look like it is orbiting something invisible, so keep
each one roughly symmetric about (0, 0, 0).

## Using them in Godot

`scripts/props.gd` does this already — `StationProps.make(name, palette)`. It goes through
`Kit`, which caches each `.glb` once and bakes out any import transform, addressing a prop as
the piece `"props/<name>"`. Materials are applied as **per-surface overrides**, so one prop is
one `MeshInstance3D` costing one draw call per material on it. That is why props are not merged
into the hull batches: they have to spin and be shoved (`Station.shove_props`) individually.
Place a dozen, not a hundred.

Godot writes the `.glb.import` sidecars itself the first time the project is opened or
`godot --headless --path . --import` is run; they are not generated by the build script.

## Regenerating

```
python3 tools/build_props.py              # all of them -> kit/props/*.glb
python3 tools/build_props.py prop_crate   # just one
python3 tools/validate_glb.py             # re-parse and check every glb under kit/
python3 tools/render_props.py             # preview contact sheet -> out/props_sheet.png
```

`tools/kitlib.py` holds the primitives (box, cylinder, tube, sphere, torus, frame), the
material palette and the glTF writer; `tools/build_props.py` holds one function per prop.
Adding a prop is a new `@prop("name", "description")` function — nothing else to register.

Everything is pure standard library: no numpy, no Blender, no OpenGL. `render_props.py` is a
small z-buffered software rasteriser written because the sandbox has neither Blender nor GL —
it is there to check silhouettes, proportions and material assignment, and it exaggerates glass
opacity so visors are visible. Judge the assets in Godot, not in it.
